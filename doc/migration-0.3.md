# Migrating an external from median 0.2 to 0.3

0.3 replaces the `external!` macro with a derive, an inherent impl marked `#[median::methods]` and `ext_main!`, and replaces raw object pointers, boxed outlets and trampolines with handles and typed registration. There are no deprecated aliases: every old name below is gone.

Toolchain: `median` is edition 2024 with `rust-version = "1.85"`, so use Rust 1.85 or newer. Your own crate may be on edition 2018 or later, but `c"..."` literals (used below) need edition 2021+; the examples and the template are on 2024. Keep `panic = "unwind"` in the release profile (the trampolines catch panics).

The new forms below are checked against the code at `xnor/api-redesign`; `median/examples/simp` and `median/examples/simp_explicit` are the reference. Most names are in `median::prelude::*`; the attribute builder (`median::attr::AttrBuilder`), errors (`median::error::MaxError`) and the buffer types (`median::buffer::{BufferReference, BufferLocked, BufferEdit, EditError, AtomicSample}`) are not.

| buffers | `BufferLocked` owned by the guard: owned by the guard, no lifetime: `channel_slice(ch) -> &[f32]`, `channel_slice_mut`, `channel_iter()` of slices, `Index<usize>`, `samples() -> *mut f32` (now `unsafe fn samples_ptr`) | `BufferLocked<'_>` borrows the reference (`!Send`) and is read-only: `frames()`, `channels()`, `as_slice()`, `frame(i)`, `sample(frame, ch)`, `channel_iter(ch)`, over `AtomicSample` (`.get() -> f32`, `.set(f32)`), because Max and other threads may write the same memory. Data is interleaved: a channel is a strided view. To write, use `BufferReference::edit() -> Result<BufferEdit<'_>, EditError>` (main thread only; `as_mut_slice`, `frame_mut`, `channel_iter_mut`). `try_lock`, `exists`, `channels`, `frames` no longer take a mutex. |

| class setup | `fn class_setup(c: &mut Class<MaxObjWrapper<Self>>)` (MSP: `MSPObjWrapper<Self>`) | unchanged. It now runs after the field attributes and `#[median::methods]` registrations. |

## `simp`, before and after

Sequential, abridged to the parts that changed. Full versions: 0.2.0 is `git show 797ae2b:median/examples/simp/src/lib.rs`; 0.3 is `median/examples/simp/src/lib.rs`.

0.2:

```rust
use median::{
    atom::Atom, attr::{AttrBuilder, AttrType}, builder::MaxWrappedBuilder, class::Class,
    clock::ClockHandle, inlet::MaxInlet, max_sys::t_atom_long, num::{Float64, Int64},
    object::MaxObj, outlet::OutList, post, symbol::SymbolRef,
    wrapper::{attr_get_tramp, attr_set_tramp, MaxObjWrapped, MaxObjWrapper},
};

median::external! {
    pub struct Simp {
        value: Int64,
        fvalue: Float64,
        clock: ClockHandle,
        list_out: OutList,
    }

    impl MaxObjWrapped<Simp> for Simp {
        fn new(builder: &mut dyn MaxWrappedBuilder<Self>) -> Self {
            builder.with_default_inlet_assist("first inlet");
            builder.add_inlet_with_assist(MaxInlet::Float(Box::new(|_s, v| {
                post!("got float {}", v);
            })), "my float inlet");
            builder.add_inlet(MaxInlet::Int(Box::new(Self::int)));
            let _ = builder.add_inlet_with_assist(MaxInlet::Proxy, "my proxy inlet");
            Self {
                value: Default::default(),
                fvalue: Default::default(),
                clock: builder.with_clockfn(Self::clocked),
                list_out: builder.add_list_outlet_with_assist("my list out"),
            }
        }

        fn class_setup(c: &mut Class<MaxObjWrapper<Self>>) {
            c.add_attribute(
                AttrBuilder::new_accessors("foo", AttrType::Float64,
                    Self::foo_tramp, Self::set_foo_tramp).build().unwrap(),
            ).expect("failed to add attribute");
            // ... the same again for "blah"
        }
    }

    impl Simp {
        #[bang]
        pub fn bang(&self) {
            let i = unsafe { median::inlet::Proxy::get_inlet(self.max_obj()) };
            median::object_post!(self.max_obj(), "from rust {} inlet {}", self.value, i);
            self.clock.delay(10);
        }

        #[int]
        pub fn int(&self, v: t_atom_long) {
            self.value.set(v);
            self.attr_touch_with_name(SymbolRef::try_from("blah").unwrap()).unwrap();
        }

        #[attr_get_tramp]
        pub fn foo(&self) -> f64 { self.fvalue.get() }

        #[attr_set_tramp]
        pub fn set_foo(&self, v: f64) { self.fvalue.set(v); }

        // "blah": the same pair again, over `self.value`

        pub fn clocked(&self) {
            let _ = self.list_out.send(&[1i64.into(), 12f64.into(),
                SymbolRef::try_from("foo").unwrap().into()]);
        }
    }
}
```

0.3:

```rust
use median::prelude::*;

#[derive(MaxObject)]
#[max(name = "simp")]
pub struct Simp {
    obj: ObjRef,
    // the "blah" attribute pair is now one field attribute
    #[attr(clip(0, 100), label = "Value", category = "Simp", save)]
    value: Int64,
    fvalue: Float64,
    clock: Clock,
    list_out: Outlet<List>,
}

impl MaxObjWrapped for Simp {
    fn new(builder: &mut MaxBuilder<Self>) -> Result<Self, NewError> {
        builder.inlet(Inlet::default().assist("first inlet"));
        builder.inlet(Inlet::float(|_s: &Self, v| post!("got float {}", v)).assist("my float inlet"));
        builder.inlet(Inlet::int(Self::int));
        builder.inlet(Inlet::proxy().assist("my proxy inlet"));
        Ok(Self {
            obj: builder.obj(),
            value: Int64::new(0),
            fvalue: Default::default(),
            clock: builder.clock(Self::clocked),
            list_out: builder.outlet(Outlet::list().assist("my list out")),
        })
    }
    // no class_setup: attributes are declared on the field and the getter
}

#[median::methods]
impl Simp {
    #[bang]
    pub fn bang(&self) {
        let i = self.obj.proxy_inlet();
        median::object_post!(&self.obj, "from rust {} inlet {}", self.value, i);
        self.clock.delay(10);
    }

    #[int]
    pub fn int(&self, v: t_atom_long) {
        self.value.set(v);
        let _ = self.obj.attr_touch_with_name(c"value");
    }

    #[attr]                                   // getter; `set_foo` below is found by name
    pub fn foo(&self) -> f64 { self.fvalue.get() }
    pub fn set_foo(&self, v: f64) { self.fvalue.set(v); }

    pub fn clocked(&self) {
        let _ = self.list_out.send(&[1i64.into(), 12f64.into(), SymbolRef::from(c"foo").into()]);
    }
}

median::ext_main! { Simp }
```

Notes on the port: the `_tramp` functions and the whole of `class_setup` disappear. The old "blah" accessor pair (over `value`) is now the `#[attr]` on the `value` field, so it is named "value", and `int` touches that name. The shipped 0.3 example also has a `Queue`, a deferred `read`, a `set` message and an optional creation argument, which have no 0.2 counterpart.

## Gotchas

- **`in<N>`/`ft<N>` renumbering.** Inlets are numbered per kind, from 1, not by position. In `simp` the int inlet is `in1` now (it was `in2`: position 2); the float inlet is `ft1`. Anything that sends `in2 5` to the object (patchers, tests) must change. Proxy inlets are the exception: the id `self.obj.proxy_inlet()` returns is the inlet's position (3 for `simp`'s proxy). More than 9 `Inlet::int` or 9 `Inlet::float` inlets is a construction error.
- **Inlet 0.** It exists unless you describe it. `Inlet::default()` describes it and must be the first `builder.inlet` call; otherwise the first description is inlet 1. For MSP, signal inlets come first and occupy `0..n`; a signal inlet after another kind is an error. A mistake in the description fails construction (an `Err` posted as `median: ...`) rather than panicking.
- **Mixed `f64` typed selectors are rejected.** A `#[sel]` (or `add_sel`) whose arguments mix `f64` with `t_atom_long`/`SymbolRef` does not compile (Max passes them in different registers on x64). Use `#[sel_gimme("name")]` / `add_sel_gimme` and read the atoms. The macro reports it at the method when the types are spelled `f64`; behind a type alias, or from `add_sel`, a `const` assertion fires instead. That assertion is evaluated by `cargo build`, not `cargo check`, so `check` can pass on code that fails to build. The same applies to `builder.clock(f)` with a capturing closure (`f` must be zero-sized): use `clock_with`. Run `cargo build` before believing a green check.
- **Reserved selectors.** `notify`, `assist`, `inletinfo`, `dsp64`, `ft1`..`ft9`, `in1`..`in9` are registered by median and refused by `Class::add_*` and `#[sel]` (`MaxError::Duplicate`, or a spanned error). For MSP classes `signal`, `userconnect`, `nsiginlets`, `enable` too; the macro cannot know the kind, so that one fails at registration, not at compile time. `#[median::methods]` still rejects `#[notify]`; `#[savestate]` is supported.
- **Duplicate attributes are errors.** A name registered twice fails the class registration, whether from a field `#[attr]`, a getter `#[attr]`, `add_attr*` or `add_attribute`. Registration order is field attributes, then `#[median::methods]`, then `class_setup`.
- **One marker per method**, one registration per selector in an impl, and receivers must be `&self`. Methods may not be generic, async or `unsafe`. Derive and `#[median::methods]` reject generic types.
- **Do not leak `ObjRef` or `Outlet` out of the object.** They are `!Send` and `!Clone` handles valid for the object's lifetime; `Box::leak`, a `thread_local!` or a `static` holding one is a use-after-free that safe code is not stopped from writing. Keep them in the struct. The same note is on `Clock` and `Queue`: they are armed after `new` returns and disarmed before your struct drops.
- **`obj` inside `new`.** `builder.obj()` gives a handle before the object is complete. Max calling back into the object during `new` is refused (an error is posted), so don't send messages to yourself from `new`.
- **Callbacks must not free their owner.** A clock callback, a `Queue` callback or a deferred method must not delete its own object or drop its own `Clock`/`Queue` (that blocks the thread forever, instead of freeing the object under the running callback). Opening a modal dialog from one is fine: if Max runs the same queue or clock in the dialog's event loop, it runs nested. Don't create a class or a `Clock` inside `class_setup`, `Methods::register` or `register_attrs` either.
- **Real-time.** Queuing a deferred call allocates and locks: never send a `#[defer]`/`#[defer_low]` message from `perform`. `Queue::set` from `perform` is intended (with `median::fifo`) but unverified under load. Outlets are for the main and scheduler threads, not `perform`; this is documented, not enforced.
- **Errors in `new` are real now.** A `new` that returned a value despite bad arguments (0.2 had no way to refuse) should now return `Err`. A panic in `new` is caught and has the same effect, but `Err` gives a clean message.
- **Setter errors.** A setter's `Err` reaches Max as `MAX_ERR_GENERIC` and the message goes to `report_error`.
- **Field attributes need atomics.** `#[attr]` on a field needs a type implementing `AttrField` (`Int64`, `Float64`, `Float32`); a plain `i64` or `f64` field will not compile.
- **`default` is informational.** `default = ..` on an attribute is shown in the inspector but median does not apply it; set the initial value in `new`. `save` needs no other support.
- **Hand-written `Methods`/`FieldAttrs` impls** return `MaxResult<()>`, so use `?`. An `Err` panics the registration (posted to the console) and the class is not registered. `simp_explicit` is `simp` with every generated impl written out; port by hand from it if you need conditional or computed registration.
- **Max validation.** The user has checked buffer-follow/playback in `hello_dsp~` and float-to-int message rejection. Patch 01 additionally confirmed loadbang, float delivery, int-to-float rejection, and deferred main-thread delivery with Overdrive on/off and DSP off (2026-10-26; see `validation-max.md`). Other changes, including dictionaries and Jitter, have only mock/build coverage. The plan's Status lists what to check by hand (the `in`/`ft` hiding in the message menu, `save` restore, DSP-on/modal deferred delivery, `BufferEdit` locking).

## Dictionaries and Jitter

`Dict` owns one reference: cloning shares it, `deep_clone()` copies it. Inserting an owned
`Dict` transfers that reference; inserting `&Dict` copies; `insert_shared` shares explicitly
and rejects cycles made through median. Reads copy or retain while transaction-locked. Register
before `Outlet<Any>::send_dict`; keep the returned handle alive. `#[dictionary]` receives an
owned `Dict`; `#[savestate]` receives `&Dict`. These callbacks cannot be deferred implicitly.
`from_json`, `from_atoms`, `read`, `write`, and `dump` use the SDK parsers/file APIs. `rename`
returns the dictionary at the requested name; it does not move the original's entries.
Call `notify_modified` outside transactions. Ordinary list/anything outlets reject `A_OBJ`;
use `send_dict`, whose delivery failure is `DictSendError::Send(SendError)`. Raw object/array
inspection is explicitly unsafe. In-memory `to_json` awaits host verification; see
[the container plan](plan-containers.md).

Jitter externals use `#[max(kind = matrix_op)]` with `jit::MatrixOp`, or `#[max(kind = gl)]`
with `jit::Ob3d`. The derive registers both Jitter and Max classes. Keep `JitBuilder::obj()`
in your struct if you need a `JitObjRef`. Methods take `&self`; attributes need atomics.
MOP/ob3d creates the iolets and provides assistance. Matrix data references require explicit
unsafe access contracts, even with a matrix lock held. GL callbacks get `&DrawContext`; do not
use GL operations from `Drop`. See `jit_scalebias` and `jit_gl_simple` for complete examples.

Jitter constructors now take `&mut JitBuilder<Self>`. Add custom iolets with
`b.inlet(Inlet::int(|s: &Self, value| { /* update s */ }))?`, `Inlet::float`, or
`Inlet::proxy`, and `b.outlet(Outlet::list().assist("results"))?`. Inlets follow the SDK
matrix inlets; outlets follow the matrix outlets and dumpout. The returned `InletId` is
the final position. Store `b.max_obj()?` to read `proxy_inlet()` in forwarded messages;
`b.obj()` still refers to the Jitter core. Do not describe the SDK's inlet 0 again.
Extra iolets are supported for fixed-count matrix operators and GL objects; standalone
Jitter cores and variable-count MOPs return an error for these requests.

The `jit::ob3d` resource helpers borrow the callback's context: `GLChunk` owns its matrices
and supports fallible copying; matrix access and drawing retain their unsafe data contracts.
`GLDataBuffer` and `GLGeometry` require unsafe ownership adoption. Geometry `set_data_copying`
additionally requires a verified synchronous-copy ABI; the public SDK headers do not establish
it. Keep these owners inside the callback, where cleanup has a context, rather than in object fields.
